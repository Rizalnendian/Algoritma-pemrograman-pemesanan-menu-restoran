## Deskripsi
Proyek ini adalah implementasi algoritma pemrograman sederhana untuk sistem pemesanan menu restoran. Kode ini dirancang untuk mendemonstrasikan konsep dasar pemrograman seperti input/output, loop, kondisi, dan struktur data sederhana. Sistem ini memungkinkan pengguna untuk memilih menu, menghitung total harga, dan menampilkan ringkasan pesanan.


## Fitur
- **Daftar Menu**: Menampilkan menu restoran dengan harga.
- **Pemesanan**: Pengguna dapat memilih item menu dan jumlahnya.
- **Perhitungan Total**: Otomatis menghitung total harga pesanan.
- **Ringkasan Pesanan**: Menampilkan detail pesanan sebelum konfirmasi.
- **Sederhana dan Edukatif**: Cocok untuk pembelajaran algoritma pemrograman dasar.
